## Getting Started

Playwright Browsers lists the Chromium, Firefox, and WebKit builds shipped with each Playwright release.

Catalog data lives in `playwright-releases.json`. The site is generated into `_site/`.

## Serve

```bash
pnpm serve
```

## Test

```bash
pnpm test
```

## Update

```bash
pnpm update
```
